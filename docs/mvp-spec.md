# 數字油畫 Agent MVP 規格

## 目標

將 `sample/cats.png` 轉成50×40公分、300 DPI、36色、成人零基礎可完成的數字油畫套件。MVP 使用一個 Orchestrator Agent；程式碼控制固定步驟、重試上限、人工批准與檔案狀態。

## 不變條件

- 主體必須恰好為三隻貓與一顆毛線球。
- 保留每隻貓的動作、方向、比例和相對位置。
- 所有原圖可見的眼睛、虹膜、瞳孔、高光、耳朵、鼻子與嘴巴必須完整。
- 中間貓保持橘白色、項圈與鈴鐺；左右貓保持深色虎斑與白色部位。
- 不得互換毛色、增加動物、增加肢體或重新設計五官。

## 可改動項目

- 磨石子地板簡化為較大的米、灰、棕色區域。
- 木紋、窗格小反光和微小陰影可以合併。
- 毛髮與細虎斑可以改成較寬、連續的形狀。
- 允許統一接觸陰影、光線與色溫，但不可移動主體。

A、B 的首要目標不是「看起來像完成的油畫」，而是建立可供初學者著色的彩色分區草圖：使用平坦、平滑、封閉的大色區，不得出現可見筆觸、單根毛髮、細碎虎斑、木紋或單顆磨石子。油畫感只從 D 開始加入。A 使用純 `#FF00FF` 背景，讓白色毛髮與眼睛高光能安全去背。

## A–E 契約

| 階段 | 輸入 | 工作 | Gate |
|---|---|---|---|
| A | 原圖 | 主體提取；轉成大型封閉平塗色區 | 自動保存與檢查 |
| B | 原圖 | 背景補洞；轉成大型封閉平塗色區 | 自動保存與檢查 |
| C | 原圖、A、B | 特徵對齊、洋紅去背、逐像素確定性合成 | 人工批准 |
| D | C、原圖 | 簡化油畫風 | 自動保存與檢查 |
| E | D、原圖 | 移除細碎筆觸和色斑 | 人工批准 |

每階段最多一次初稿與兩次帶明確 feedback 的修正。C 未批准不得進入 D；E 未批准不得產生正式線稿。

C 不呼叫 ImageGen。程式先以原圖估計 A 的單一縮放、旋轉與位移，再移除洋紅背景並合成到 B。`composite.json` 必須證明完全不透明的主體像素最大 RGB 差為 0，避免合成階段重新產生毛髮或改變五官。

## Protected Features

色彩量化保留兩個強制色彩錨點：暖白與深褐黑。自動保護器尋找與深色細節相鄰的微小高亮區域，例如眼睛高光；人工遮罩可額外指定永不合併區域。

普通小區域會合併到色彩最接近的相鄰色塊。受保護小區域保留；若無法容納內部編號，使用直向編號或外部引導線。

## 36色輸出

- ImageGen 不承擔精確36色的責任，只負責產生較乾淨的視覺母圖。
- 後處理以加權 K-means 產生可重複的36色色盤。
- Protected pixels 在取樣時取得高權重，強制色彩錨點不參與中心更新。
- 一般小元件依面積、鄰接色與色差合併。
- 輪廓由最終區域標籤計算，不直接從原圖邊緣偵測。

## 尺寸與文字

- 實體尺寸：50×40公分，橫式5:4。
- 主輸出：5906×4724 px，300 DPI。
- 工作解析度：2000 px 寬。
- 最小印刷數字高度：3 mm，約35 px。
- 優先水平編號，其次直向兩位數，最後使用外部引導線。

## 產物與可追蹤性

每次 run 保存 `spec.json`、`plan.json`、`state.json`、每階段各 attempt、複雜度 metrics、A–E 最新別名，以及 final 目錄。任何階段失敗都能確認使用的參考圖、prompt、feedback、attempt 與輸出。

## MVP 邊界

- 暫不提供圖形化遮罩編輯器。
- 自動高光偵測是保守 heuristic，不取代人工確認。
- ImageGen 是機率性輸出；不變條件仍需在 C、E 人工 gate 檢查。
- MVP 先使用 CLI，不含帳號、雲端儲存與佇列系統。
